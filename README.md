# TinyFField (tiny finite field)

Implementing some basic abstract algebra structures.

### Goal

The goal for now is to implement $\mathrm{GF}(2)[x]/(x^8 + x^4 + x^3 + x + 1)$ as used in the AES key schedule,
then verify all the inverses against the ones listed in [this NIST
PDF](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.197-upd1.pdf).

Just for learning and fun.
